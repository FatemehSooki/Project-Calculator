# [✨ Modern Calculator](https://fatemehsooki.github.io/Project-Calculator/)

A sleek and interactive calculator application built with HTML, Tailwind CSS, and Vanilla JavaScript, featuring a modern glassmorphism-inspired interface, smooth animations, and responsive design.

<img src="img/Screenshot (998).png" width="700">

## 🚀 Overview

This project is more than a simple calculator. It combines functional JavaScript logic with a modern user interface to create an engaging user experience.

The application allows users to perform basic arithmetic operations through an elegant glassmorphism design enhanced with animated backgrounds, interactive buttons, and responsive layouts.

## ✨ Features

* Clean and modern Glassmorphism UI
* Responsive design for different screen sizes
* Interactive button animations
* Dynamic calculation using JavaScript
* Addition, subtraction, multiplication, and division operations
* Clear screen functionality
* Custom SVG operator icons
* Animated background effects
* Social profile integration

## 🛠️ Tech Stack

* HTML5
* Tailwind CSS
* JavaScript (ES6)
* SVG Icons
